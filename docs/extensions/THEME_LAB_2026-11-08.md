# Isolated theme lab — 2026-11-08

User explicitly authorized a branch push and a separate test URL with selectable themes and saved example games. All game/browser/build/test execution takes place on Oracle ARM64, never the Windows workstation.

## Product behavior

The normal catalog remains Classic only. Explicit `TADAZZ_DEMO_CATALOG_ENABLED=true` adds the source-controlled Cosmic Night and Jade Studio definitions to the authenticated manager catalog. Both use the reviewed Classic renderer/choreography, with original Canvas-generated backgrounds, transparent wordmarks, three-second WebM openings, embedded-only Lottie overlays, distinct palettes and Rubik. Jade uses quieter audio levels. Existing repository sounds retain their provenance; these are demonstrations, not independently authored motion engines or customer-published packages.

The demo flag only enables authenticated GET `/api/themes/catalog` and exact-version room selection. Installer/workspace APIs remain disabled when the installer is OFF. No synthetic approval, customer upload bypass or global registry mutation is used. Existing editor settings, save/import/export, room snapshots, host/player/display and audio machinery handle the definitions.

Six examples are saved through the real composite quiz API: Quick Quiz and Audience Picks for each of Classic, Cosmic Night and Jade Studio. Each contains three questions. Select a saved game in the normal manager screen, or open a game in Studio → Settings to choose another theme. Saved examples remain editable.

## Reproduction and rollback

`packages/e2e/scripts/generate-theme-lab.ts` creates original assets remotely using headless Canvas/MediaRecorder. Checked-in assets are the deployment inputs; regeneration intentionally creates a new recording and must refresh manifest hashes.

`packages/e2e/scripts/seed-theme-lab.ts` requires the explicit remote guard, exact loopback URL and private seed receipt; it refuses to rerun over an existing receipt. It creates saved games, without starting rooms.

`playwright.theme-lab.config.ts` requires explicit remote URL and seed receipt. It verifies all three editor choices, selection/save/restore, demo asset bytes/SHA256 and video decoding; each saved sample verifies room selection without fallback, participant joining, voting, pause, display synchronization and reload.

To retire the lab: stop only `tadazz-theme-lab`; remove only the marked isolated-theme-lab hostname block after checking current Caddy configuration, validate and gracefully reload. Preserve the private config and seed receipt unless the owner explicitly requests deletion. Never restore an old entire Caddyfile over other agents' changes. No production rollback is necessary because production is not replaced.
