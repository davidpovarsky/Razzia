## מה נמסר במנוע הערכות

- Classic 1.0.0 בלבד, manifest עם 15 מצבי תצוגה ו־16 אירועי אודיו,
  registry של רכיבים מהימנים, resolver טהור, וריאציות מוגבלות ונכסים עם
  hashes, גדלים ופרטי מקור. לא נוספו משפחות דמה או קובצי צליל מומצאים.
- חיבור לבמה הקיימת ול־Studio הקיים, בחירות של הערכה הפעילה בלבד,
  Preview מקומי, בחירת מדיה, השתקה, reset לפי אזור וארכיון התאמות.
- שימור metadata ב־native bundle, JSON, TadaShowV1 ו־XLSX; תוקן אובדן
  `motionKit` בהמרות הישנות. מזהה ערכה לא מוכרת נשמר וה־fallback הוא
  לתצוגה בלבד, עם אזהרה למנחה.
- אותו AudioCuePlayer: מוזיקה מתחילה מחדש בשאלה/epoch חדש, אינה מתאפסת
  בכל tick, אפקטי שחקן כפופים לערכה, סיום ידני נבדל מפקיעת זמן,
  וחסימת autoplay ממתינה ללחיצת Enable sound.
- תבנית ו־skill מקומי `tadazz-theme-creator`, validator המשתמש בסכמת Zod
  האמיתית, ובדיקות נכסים/זכויות/hash/MIME/קבצים אסורים. חבילת ה־ZIP
  ההיסטורית לא נמצאה ולכן לא נטען שנקראה או שולבה.
- מסלול review/sign/rollback מבודד לשני tenants נבדק **כסביבת ייחוס
  בזיכרון בלבד**. אין API התקנה/פרסום חשוף, אחסון tenant מתמשך או
  marketplace פעיל. קוד לקוח מתוך ZIP אינו נטען או מורץ.

תיעוד החוזים, האפשרויות האמיתיות והוספת ערכה:
`SHOW_THEME_ENGINE.md`. הוראות הסוכן: `.agents/skills/tadazz-theme-creator/SKILL.md`.
