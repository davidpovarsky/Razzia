## What was implemented

compiled-index-schema.ts supplies bounded strict revision-2 records for tagged
Git and locked-package sources; native resource and artifact indexes; untrusted
registry descriptors with the exact silent manager/spectator five-phase matrix;
unknown/reviewed rights assessments and operation/scope/license-obligation review
receipts; dependency provenance; pnpm CAFS membership receipts; and separate
platform-font versus non-hermetic native typography/environment records. Reuses
existing exact refs, bounded JSON, canonical JSON and freeze helpers. Guards
accessors/prototypes/cycles/sparse/hidden fields before recursive parsing; enforces
path/version/digest/MIME/count/number bounds, strict keys, canonical ordering,
case collisions, own named exports and known hash-cycle exclusions. There are no
permissive defaults or budget increases; the 100 MB aggregate diagnostic ceiling
is a validation ceiling, not an approved renderer performance budget.

compiled-index-validation.ts checks canonical text and raw byte hashes, missing/
extra files, artifact/resource/source/license cross-binding, optional untrusted
registry index hashes/renderer/budgets, and reports remaining actual closure,
response/decode/license, loader/export/SRI/CSP and browser/editor-isolation gates.
It does no IO, fetching, module execution, serving or renderer registration.
A consistent byte map is diagnostic evidence, not production immutability proof.

compiled-index-authority.ts is host-only. Candidate reviewed labels/receipt hashes
cannot add authority. Rights matching requires a private root-reviewed receipt
bound to exact resource bytes, license references, intended operation, renderer
and source-theme scope; no executable scope is installed. Store receipt shape
binds exact lock/SRI/package key, whole original index and selected row hashes,
row locator/alias, byte size/SHA-512/mode, observed SHA-256 and referenced immutable
CAFS inputs. Diagnostic SHA-512/SRI consistency is not independent input proof:
actual original index-row/content verification and root review remain external
requirements before a future immutable host receipt can exist. This is reviewed
store-membership attestation, never tarball re-extraction or signature proof.
Installed platform-only Rubik does not become a renderer requirement.

compiled-index.test.ts authors 29 meaningful cases (including parameterized paths)
for canonical/tamper/missing-file/license/source/index checks, forged authority,
mode/SHA-512/CAFS inputs, prototype/accessor/cycle/sparse data, order/case/decode
metadata, registry capability/export rejection, and typography scope/limitations.
Fixtures use small explicitly synthetic diagnostic bytes. They do not pretend to
be decoded product images, a renderer artifact, a positive rights grant or a pin.
