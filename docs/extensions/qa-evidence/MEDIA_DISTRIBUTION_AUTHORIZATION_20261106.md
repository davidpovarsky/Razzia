# TADAZZ soundtrack distribution authorization — 6 November 2026

The project owner explicitly confirmed in this Codex chat that they obtained
express distribution permission from the rights holders for all eight selected
recordings, and directed their complete inclusion in the release:

> קיבלתי מהם אישור הפצה!! הכל בסדר!!! תכניס אותם לשחרור בשלמות!!

This is the release authorization evidence supplied by the owner. The earlier
curation manifest's `readyForProductBundling=false` reflects the previous review
state; it is superseded for this release by that explicit owner confirmation.
No claim is made that Codex has seen the underlying correspondence.

All eight original source files are preserved. Source SHA256 and byte lengths
were checked against the original curation manifest before preparing copies.
The opening uses the original PCM WAV bit-for-bit, preserving its exact 12 s
duration. Browser MP3 copies of the other seven recordings contain their full
recordings. The round-start runtime deliberately plays a short cue as specified;
this does not truncate the distributed source recording.

The existing `/media/tzila-determined-pursuit-20261105.mp3` voting recording is
not replaced, re-encoded, renamed or changed. Its enabled=true, loop=true and
volume=0.38 configuration remains intact.

Release media provenance and generated-file hashes are recorded in the release
manifest. Media is installed only into the existing tenant's authorized media
directory, retaining the application's manager and room-media authorization.

Sources: the eight individual OpenGameArt pages, the original local
`Tada-media-curation/manifest.json`, `SOURCE_AND_LICENSE.md`, `license_evidence/`,
and round 2–4 feedback. The existing Apple Loops note for Determination is
