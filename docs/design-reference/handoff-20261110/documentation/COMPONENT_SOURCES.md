## Rule for future changes

Each borrowed component MUST include an adjacent comment with: library and component name, permanent link (prefer commit/blob SHA), licence/copyright, exact local modifications, where mounted, and before/after screenshot test. If no upstream source code was used, label it as a **local TADAZZ implementation**. No invented attribution to suggest a feature was purchased or copied.

## Explicitly excluded

- `packages/web/src/features/quizz/components/studio/**` and the existing `StudioShell`.
- `packages/web/src/pages/manager/quizz/**` (the existing game editor routes).
- Game runtime, telephony, manager controls, checkout/payment implementation, production deploy.

This design branch may eventually add a new marketing and account shell but must never overwrite the existing game editor. New/Edit should route to the authentic editor; there must not be a second editable demo model masquerading as persisted quiz data.
