TADAZZ Question Background Code Animation

Files:
- index.html  -> main animated background demo (open in Chrome/Edge)
- background.png -> static stage image used underneath the animation

What it does:
- subtle moving light beams
- pulsing ambient glows
- glints across the blue and citron Z structures
- shimmering floor reflection
- moving particles around the central ellipse
- optional Q&A overlay demo

How to use:
1. Keep background.png in the same folder as index.html
2. Open index.html in Chrome or Edge
3. Click Fullscreen for live preview
4. Use the intensity slider if you want quieter or stronger movement

For web integration:
- The HTML is self-contained and can be embedded in an iframe or adapted into your project.
- If desired, the CSS/JS can be extracted into your app instead of using the full demo page.
